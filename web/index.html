信源分级标准

判决只能依据真实检索到的网页；网页不是平等的。

A
权威 · 可作判决硬依据
政府与卫健/疾控部门（.gov.cn）、人民日报/新华社/央视等央媒、官方辟谣平台、科普中国、三甲医院与高校。
B
可信 · 可作参考佐证
正规地方媒体（澎湃、新京报等）、专业检验检测与研究机构。方向与 A 级一致时增强证据，不能单独定案。
C
存疑 · 只作线索
百家号、搜狐号、抖音/小红书/知乎用户内容、无来源订阅号。与 A 级矛盾时以 A 级为准。

真实性保障

· 每条结论附可点击的原文链接，引文逐字摘自真实网页；
· 模型编造的链接和引文会被自动丢弃；
· 没有权威源支撑时，不下「谣言/属实」判决，而是诚实标注「查无实据」；
· 核查记录只保存在你自己的手机浏览器里，不上传服务器存储。

使用须知

结论仅供参考，不替代医疗诊断；重大健康问题请遵医嘱，偏方不能替代正规治疗与药物。核查由大模型自主完成，可能存在错误，请以权威机构发布信息为准。联网能力由豆包深度搜索提供。

Key 怎么被使用

· Key 只保存在你这台设备的浏览器（localStorage），不上传到任何数据库；
· 每次核查时，浏览器把 Key 随请求临时捎给本服务，服务端仅在内存中用于调用火山引擎、用完即弃，不写盘、不记日志；
· 你也可以什么都不填——若服务端自己配置了 Key，会自动兜底使用；
· 建议在 HTTPS 或本机 localhost 下使用，避免明文传输。

去哪申请 Key

· 方舟 LLM：火山引擎方舟控制台创建 API Key（Doubao 模型）；
· 豆包搜索：火山引擎「联网搜索 / Search Infinity」控制台开通并取 Key；
· 两个 Key 通常可在同一火山账号下获取，填入后点「测试连通」即可。

清除本机 Key

清除后，浏览器里保存的 Key 会被删除。
